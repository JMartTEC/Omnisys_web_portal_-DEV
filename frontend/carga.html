Reglas de carga

Configurar agente RAG

Cada gobierno puede usar el agente local del portal o conectar su propio agente, siempre que exponga el mismo contrato POST /api/v1/rag/query.

POST {url}/api/v1/rag/query
{ "pregunta": "string", "gobierno": "integracion", "dominio": null, "top_k": 4 }
→ { "respuesta": "string", "fuentes": [{ "titulo", "dominio", "fragmento", "score" }], "agente": "integracion", "modo": "remoto" }
